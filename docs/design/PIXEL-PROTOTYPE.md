# Moonwater pixel-art prototype

User approved the character designs on 2026-09-20, requesting coarser pixels and more visible animation. This supersedes the earlier anime/woodcut experiments as the current prototype direction.

## Scope

Three original concept characters (Pip, Selene, Aldren), an atmospheric village scene, and a deterministic free summon preview. Enter via Home > Visit Moonwater, or /?pixelPreview=1. These are art studies, not roster entries or balanced cards. No economy or collection writes. Sprite sheets use four frames, with CSS ambient fireflies, drifting mist, and a summon charge/reveal. Motion toggle and reduced-motion support included.

## Assets and provenance

Generated using the built-in imagegen tool, not hand-pixelled. Final active files: public/art/pixel/{pip,selene,aldren}-sheet-v2.png and public/art/pixel/moonwater.png. Original approved v1 sheets preserved. Reference research informed the direction, but no third-party artwork was copied into the project. Four-frame loops remain prototype quality: small differences between generated frames need manual cleanup before production.

## Revision prompt (applied independently to each approved character sheet)

Edit this exact approved character animation spritesheet. Preserve character identity, cuteness or beauty, costume, color scheme, scene, and 2x2 layout. Simplify it substantially into AUTHENTIC CHUNKY LOW RES PIXEL ART: each quadrant should look like a 96x96 pixel image enlarged with nearest-neighbor, approximately 6x6 solid square blocks per logical pixel at this output size. Only 24 flat colors. Large readable clusters, no tiny dither texture, no smooth gradients or anti-aliasing, no thin high resolution lines. Redraw simplified forms rather than add a filter. Keep EXACTLY the same background and character size/anchor in all four frames, floor identical. Four frames show small cyclical cloak/tail motion and a brief blink (guardian visor glow instead). No change of pose or proportions across frames. No dividing lines or gutters. The character must remain charming and recognisable with significantly coarser pixels.
