# Moonwater expansion artwork

Created with the built-in image generation tool. Final sheets: `public/art/pixel/kingdom-expansion.png`, `undead-expansion.png`, `infernal-expansion.png`. Explicit card IDs map each cell in `src/game/cards/pixelArt.ts`. The final infernal cell is the Hound Pup battle token. Portraits render at 160 × 160 with nearest-neighbour sampling for readable faces and crisp pixels.
